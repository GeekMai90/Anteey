# 卡片盒页面多选功能需求

## 1. UI 界面

### 1.1 多选模式入口

- 在顶部工具栏右侧增加"多选"按钮
- 按钮点击后进入多选模式

### 1.2 多选模式下的界面变化

- 每个卡片右上角显示圆形复选框
- 顶部工具栏下方显示浮动的批量操作工具条，包含：
  - 已选择数量提示（例如：已选择 3 张卡片）
  - 批量操作按钮组
  - 取消多选按钮

## 2. 交互功能

### 2.1 卡片选择

- 点击卡片右上角复选框选中/取消选中
- 保持卡片原有的双击打开功能
- 支持全选/取消全选（可选）

### 2.2 批量操作功能

1. 设置卡片盒

   - 显示卡片盒下拉菜单
   - 选择后批量更新所选卡片的卡片盒

2. 标签管理

   - 批量添加标签
   - 批量移除标签

3. 卡片类型设置

   - 批量修改为 Maincard
   - 批量修改为 Bibcard
   - 批量修改为 Indexcard
   - 批量修改为 Hoplinkcard

4. 闪卡管理

   - 批量转换为闪卡
   - 批量取消闪卡

5. 批量删除
   - 删除确认提示
   - 支持撤销删除操作

## 3. 状态管理

### 3.1 Store 状态

- 多选模式状态
- 已选中卡片列表
- 批量操作执行状态

### 3.2 数据持久化

- 批量操作的数据库处理
- 操作历史记录（用于撤销）

## 4. 用户体验

### 4.1 操作反馈

- 批量操作进度提示
- 操作成功/失败提示
- 可撤销操作的提示

### 4.2 快捷键支持

- Esc：退出多选模式
- Cmd/Ctrl + A：全选（可选）

## 5. 开发规范

按项目规范完成以下开发流程：

1. 在 `/src/shared/types` 定义批量操作相关接口
2. 在 `notesService.ts` 添加批量操作方法
3. 在主进程添加对应处理方法
4. 在预加载脚本添加对应 API
5. 在 Store 中实现状态管理
6. 在组件中实现 UI 和交互逻辑
