# MCP AI增强搜索功能

## 功能概述

MCP服务现在支持AI增强搜索功能，通过调用大语言模型生成语义相关的关键词，提升搜索的准确性和覆盖范围。**对外部调用完全透明，无需修改现有API调用方式。**

## 工作原理

1. **透明增强**: 外部调用正常的搜索API，内部自动进行AI关键词扩展
2. **智能查询**: 使用原查询词+AI扩展词进行OR查询
3. **降级机制**: AI服务不可用时自动回退到普通关键词搜索
4. **配置管理**: 通过Anteey应用内设置控制AI增强功能

## API接口

### 搜索笔记（自动AI增强）

```http
GET /api/mcp/notes/search?query=皮肤护理
Authorization: Bearer your_api_key
```

**重要说明**:

- **无需额外参数**: API调用方式完全不变
- **自动增强**: 根据内部配置自动启用AI搜索
- **透明降级**: AI不可用时自动使用普通搜索

### 其他现有接口保持不变

```http
# 获取最近笔记
GET /api/mcp/notes/recent?limit=10

# 获取单个笔记
GET /api/mcp/notes/{noteId}

# 验证API密钥
POST /api/mcp/auth/verify
```

## 配置管理

AI搜索配置通过Anteey应用内的设置页面管理，支持以下参数：

| 参数          | 类型    | 默认值 | 说明                           |
| ------------- | ------- | ------ | ------------------------------ |
| `enabled`     | boolean | `true` | 是否启用AI增强搜索             |
| `maxKeywords` | number  | `6`    | 最大关键词数量（1-20）         |
| `timeoutMs`   | number  | `5000` | AI调用超时时间（1000-30000ms） |

## 搜索效果示例

### 普通搜索（AI功能关闭时）

```
查询: "皮肤护理"
结果: 只匹配包含"皮肤护理"的笔记
```

### AI增强搜索（AI功能开启时）

```
查询: "皮肤护理"
AI扩展: ["皮肤护理", "护肤", "肌肤保养", "skincare", "美容", "化妆品"]
结果: 匹配包含任意扩展关键词的笔记，结果更丰富
```

## 故障处理

### 自动降级机制

- AI服务连接失败 → 使用普通搜索
- AI响应超时 → 使用普通搜索
- AI返回格式错误 → 使用普通搜索
- 配置获取失败 → 使用默认配置
- LLM未配置 → 使用普通搜索

### 调试建议

1. 检查Anteey中的LLM配置是否正确设置
2. 查看应用日志获取详细错误信息
3. 在应用设置中测试AI功能状态
4. 临时关闭AI增强功能进行对比测试

## 最佳实践

1. **无缝体验**: 外部调用无需做任何修改，自动享受AI增强
2. **合理配置**: 在应用设置中根据需要调整AI参数
3. **监控效果**: 观察搜索结果的改善情况
4. **故障容错**: 依赖自动降级机制保证服务稳定

## 技术架构

```
外部调用 → MCP API → AI关键词扩展 → 数据库查询 → 返回结果
(无变化)    (无变化)     ↓ (失败时)
                     普通关键词搜索
```

## 依赖要求

- 需要在Anteey中配置有效的LLM服务
- 支持的AI提供商：OpenAI、智谱、Moonshot、DeepSeek、Claude、Gemini等
- 确保有足够的API调用额度
