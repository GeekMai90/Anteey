# 草稿纸功能需求说明

## 一、核心功能

### 1. 草稿页面

- 使用 TipTap 编辑器
- 固定一篇笔记作为草稿纸
- 纯文本格式
- 自动保存内容

### 2. 快速添加功能

- 全局快捷键(Ctrl+Shift+D)唤起小窗口
- 简单的文本输入框
- 输入内容后追加到草稿纸底部
- 追加规则:

* 在草稿纸末尾追加新内容
* 如果原内容末尾没有空行,自动补充一个空行
* 保持纯文本格式

## 二、技术实现要点

### 1. 内容追加方案

使用 TipTap 的 API:

```typescript
// 获取文档末尾位置

const endPosition = editor.state.doc.content.size

// 检查末尾是否需要添加空行

const needsNewLine = !editor.state.doc.textContent.endsWith('\n\n')

editor
  .chain()

  .focus()

  // 如果需要,先添加空行

  .conditional(needsNewLine, (chain) =>
    chain.insertContentAt(endPosition, {
      type: 'paragraph'
    })
  )

  // 追加新内容

  .insertContentAt(endPosition, {
    type: 'paragraph',

    content: [{ type: 'text', text: newContent }]
  })

  .run()
```

### 2. 编辑器配置

- 最小化的 TipTap 扩展配置
- 只需要基础的文本编辑功能
- 自动保存机制
- 保持光标位置

### 3. 数据存储

- 独立的 drafts 表
- 只存储一条固定记录

## 三、用户体验

### 1. 快速添加窗口

- 简洁的输入框
- 自动聚焦
- Ctrl+Enter 保存
- ESC 取消
- 保存后自动关闭

### 2. 草稿页面

- 新内容追加时自动滚动到底部
- 简洁的纯文本显示
- 编辑器始终聚焦在末尾
