# 一、基本概念

## 1. 节点层级类型

- 顶级节点（top）：如 1000, 2000, 3000
- 二级节点（second）：如 1100, 1200, 4100
- 三级节点（third）：如 1101, 1102, 4101
- 分支节点（branch-n）：如 4101-1, 4101-2, 4101-1a

## 2. 添加方向

- 同级添加（below）：在当前节点后添加兄弟节点
- 子级添加（child）：在当前节点下添加子节点

# 二、添加规则详解

## 1. 顶级节点（X000）

- 编号范围：1-5
- 同级添加规则：
  - 只能在最后添加：如 1000 后添加 2000
  - 不允许在相邻节点间插入：如 1000 和 2000 之间不能插入
  - 超过5不允许添加
- 子级添加规则：
  - 生成二级节点：如 1000 下添加 1100

## 2. 二级节点（XX00）

- 编号范围：第二位 1-9
- 同级添加规则：
  - 同一顶级节点下添加：如 4100 的同级节点是 4200
  - 不允许在相邻节点间插入：如 4100 和 4200 之间不能插入
  - 超过9不允许添加
- 子级添加规则：
  - 生成三级节点：如 1100 下添加 1101

## 3. 三级节点（XXYY）

- 编号范围：后两位 01-99
- 同级添加规则：
  - 同一二级节点下添加：如 4101 的同级是 4102
  - 允许按顺序添加：4101 -> 4102 -> 4103
  - 不允许在相邻节点间插入
- 子级添加规则：
  - 生成第一个分支节点：如 4101 下添加 4101-1

## 4. 分支节点（XXYY-N[a-z]）

- 编号规则：数字递增，可带字母后缀
- 同级添加规则：
  - 如果下一个数字编号未被占用：
    - 4101-1 -> 4101-2
  - 如果下一个数字编号已存在：
    - 添加字母后缀：4101-1 -> 4101-1a -> 4101-1b
  - 字母后缀超过z不允许添加
- 子级添加规则：
  - 生成下一级分支：如 4101-1 下添加 4101-1-1

# 三、特殊处理

## 1. 空隙处理

- 对于数字编号，如果存在空隙且允许插入：
  - 优先使用空隙中的编号
  - 如：存在 4101, 4103 时，新增节点使用 4102

## 2. 状态维护

- 添加节点时保持树的展开状态
- 仅更新必要的节点，避免整树刷新
- 保持已展开节点的子节点数据

## 3. 错误处理

- 编号超出范围时抛出错误
- 试图在禁止位置插入时抛出错误
- 无效地址格式时抛出错误
