# 新功能实现流

为保证代码的规范性和可维护性，我们统一使用以下流程来实现新功能：

1. 先确定数据结构，也就是接口，我们一般放在 /Antinet-App/src/shared/types 文件夹中
2. 如果需要创建数据表，需要在 src/db/init.ts 中创建新的数据表，我们使用的是 BetterSQLite3 数据库；
3. 在服务端创建完整的方法链路：

- 先在 src/services/ 文件夹中创建操作数据库的方法，文件命名类似于 tagService.ts;
- 然后在 src/main/ipc/ 文件夹中创建对应的主进程的方法，文件命名类似于 tagIpcHandlers.ts;
- 然后在 src/preload/api/ 文件夹中创建对应的预加载脚本，文件命名类似于 tagApi.ts；
- 然后在 src/shared/types/electron.d.ts 文件中增加方法的类型，注意分类；
- 然后在渲染端的 src/renderer/src/stores 文件夹中创建 Store，我们统一使用 window.electronAPI.xxx.updateNoteTag 类似的来调用后端的方法，我们使用的是 Pinia 的 Setup 语法，文件命令类似于 tagStore.ts；
- 然后才能在渲染端的组件中使用相应的方法。
