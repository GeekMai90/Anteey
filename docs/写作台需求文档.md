# 写作台功能需求

类似于 Gingko Writer 的写作功能，支持多列布局，支持文章管理，支持卡片操作，支持合集管理，支持文章与合集的关联。

## 1. 基础功能

### 1.1 文章管理

- 创建新文章
- 编辑文章基本信息（标题、描述等）
- 文章状态管理（草稿、已发布）
- 文章删除与恢复
- 文章合集管理（分类整理）

### 1.2 卡片操作

- 添加写作卡片（临时创建的内容）
- 添加笔记卡片（引用已有的笔记）
- 编辑卡片内容
- 删除卡片
- 移动卡片位置（调整顺序和层级）

## 2. 动态多列布局

### 2.1 布局结构

- 初始显示第一列（根级卡片）
- 选中卡片后，在右侧新增一列显示其子卡片
- 列数随层级动态增加，向右无限扩展
- 支持水平滚动查看所有列
- 每列显示当前层级的所有卡片

### 2.2 交互功能

- 点击卡片后在右侧展开新的一列
- 在当前列添加新卡片
- 拖拽调整同列内卡片顺序
- 跨列拖拽以改变卡片层级
- 选中非最后一列的卡片时，自动更新其后所有列的内容

## 3. 数据组织

### 3.1 层级结构

- 支持无限层级的卡片组织
- 维护卡片间的父子关系
- 同级卡片的顺序管理

### 3.2 合集管理

- 创建、编辑、删除合集
- 支持合集嵌套
- 文章可以属于多个合集

## 4. 用户体验

### 4.1 编辑体验

- 流畅的卡片切换
- 实时保存
- 快捷键支持
- 横向滚动导航

### 4.2 视图体验

- 清晰的层级展示
- 醒目的当前位置提示
- 自适应布局
- 滚动条显示当前可视区域
- 列之间的视觉连接（显示父子关系）

## 5. 数据关联

### 5.1 与笔记系统的集成

- 无缝引用已有笔记
- 保持与笔记的关联关系
- 笔记更新后的处理策略

### 5.2 数据完整性

- 文章数据的备份
- 防止误操作
- 数据一致性维护
